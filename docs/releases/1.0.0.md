# PromptSmith-cli 1.0.0

Initial public release.

## What it does

PromptSmith-cli is a local-first prompt preflight tool for the terminal.
It scores prompts from 0 to 100, flags ambiguity and missing context,
and refines prompts using deterministic rules, a local small language
model, or both - before the prompt reaches another AI system.

## Highlights

- Deterministic prompt scoring, missing-context detection, ambiguity
  and smell flags, and clarifying challenge generation - all available
  without loading a model.
- Rule, local-LLM, and Hybrid refinement backends, selectable per
  profile via the `backend` field.
- 35 built-in profiles and 22 built-in templates, with user overrides
  under `~/.promptsmith/profiles/` and `~/.promptsmith/templates/`
  that survive upgrades.
- Secure model acquisition: HTTPS-only downloads, GGUF header
  validation, SHA-256 verification for built-in presets, partial-file
  cleanup, and atomic promotion into the model directory.
- Runtime model switching without restarting the application.
- Local SQLite prompt history with JSON and CSV export; no automatic
  retention limit, so clear it after sensitive work on shared systems.
- Native portable builds for macOS (Apple Silicon and Intel), Linux,
  and Windows via PyInstaller - no Python installation required for
  recipients.

## Non-goals

PromptSmith is not a cloud prompt manager or model-hosting service. It
does not send prompts to remote inference APIs, does not replace the
target coding assistant or model, and does not guarantee that a small
local model will improve every prompt.

## Known limitations

- The declared Python support range (3.10-3.14) and OS matrix
  (macOS/Linux/Windows) have not been re-verified end to end against
  this exact release candidate.
- Portable ZIPs are unsigned and unnotarized. macOS Gatekeeper and
  Windows SmartScreen will prompt on first launch - see the README's
  "Share the ZIP" section for the expected, non-security-bypassing way
  to proceed.
